# Персональный контент-менеджер (маркетолог)

## Обзор функционала

Новая вкладка WEB UI с персональным контент-менеджером на базе ИИ, который помогает создавать контент-планы для социальных сетей.

## Основные возможности

### 1. Чат с нейронкой
- Диалоговый интерфейс для общения с ИИ-контент-менеджером
- Нейронка задаёт уточняющие вопросы о сообществе, целевой аудитории и целях
- В чат подгружается история постов, информация о сообществе, текущий контент-план

### 2. Создание контент-плана на разный период
- **Неделя** (7 постов)
- **2 недели** (14 постов)
- **Месяц** (30 постов)

### 3. Генерация персонального контент-плана
На основе диалога в чате ИИ генерирует:
- Темы постов разных типов (польза, вовлечение, развлечение, продажа)
- Краткое описание для каждого поста
- Рекомендуемое время публикации

### 4. Управление существующим планом
- Просмотр созданных постов
- Редактирование плана (кроме опубликованной части)
- Изменение тем, типов постов, периодов

### 5. Автообновление плана
- Автоматическая проверка истекающих планов
- Если до конца периода ≤ 3 дней, предлагается создать новый план
- Сохранение настроек и предпочтений из предыдущего периода

## API Endpoints

### Периоды контент-плана
```
GET    /api/content-manager/periods              - Список периодов пользователя
POST   /api/content-manager/period/create        - Создать новый период
PUT    /api/content-manager/period/{id}/update   - Обновить период
POST   /api/content-manager/check-expiring       - Проверить истекающие планы
```

### Чат с контент-менеджером
```
GET    /api/content-manager/chat/{period_id}           - История чата
POST   /api/content-manager/chat/{period_id}/send      - Отправить сообщение
POST   /api/content-manager/period/{id}/generate-plan  - Сгенерировать план из чата
```

### Посты периода
```
GET    /api/content-manager/period/{period_id}/posts   - Посты периода
```

## Модели данных

### ContentPlanPeriod
- `id`: ID периода
- `user_id`: ID владельца
- `period_type`: week/two_weeks/month
- `start_date`, `end_date`: Даты периода
- `status`: draft/active/completed/archived
- `community_info`: Информация о сообществе

### ChatMessage
- `id`: ID сообщения
- `content_plan_period_id`: Привязка к периоду
- `role`: user/assistant/system
- `content`: Текст сообщения
- `created_at`: Время создания

## Как использовать

1. **Перейти во вкладку "Контент-менеджер"** через главную страницу
2. **Создать новый период** (неделя/2 недели/месяц)
3. **Ответить на вопросы ИИ** о сообществе и целях
4. **Сгенерировать план** кнопкой "Сгенерировать план из чата"
5. **Просмотреть и отредактировать** созданные посты
6. **При необходимости обновить план** через чат или редактирование

## Интеграция с основной системой

- Посты из контент-плана создаются в общей таблице `posts`
- Связь через `content_plan_period_id`
- Опубликованные посты нельзя изменить
- При завершении периода автоматически создаётся новый
