Добавить сообщество ВКонтакте

Введите токен доступа сообщества. Вы должны быть администратором сообщества.

Как получить токен: ВКонтакте → ваше сообщество → Управление → Работа с API → Ключи доступа → «Создать ключ». Права: manage, photos, wall, messages, notifications. Скопируйте ключ целиком (начинается с vk1.a....) — пробелы и переносы строк недопустимы.
